# 마왕의 최종 방어선

마왕을 직접 조작해 왕좌로 몰려오는 용사들을 막는 브라우저 액션 디펜스 게임입니다.

## 바로 플레이

**[마왕의 최종 방어선 플레이하기](https://dum-sooez1111.github.io/ssr/)**

## 조작법

| 조작 | 행동 |
| --- | --- |
| `W` `A` `S` `D` | 이동 |
| 마우스 클릭 / `F` | 암흑탄 |
| 마우스 오른쪽 / `R` | 마왕검 휘두르기 |
| `Space` | 파멸의 낫 |
| `Q` | 지옥불 폭발 |
| `E` | 망자 3명 소환 — 쿨타임 없이 영혼 소비, 소환할 때마다 비용 2 증가 |

웨이브는 끝없이 이어지며 10웨이브마다 강적 **심연의 용사왕**이 등장합니다. 또한 10웨이브마다 모든 영웅의 강화 단계가 올라 체력·공격력·이동 속도가 증가합니다. 강화된 일반 영웅은 금빛 체력바와 별 단계로 구분됩니다. 망자가 살아 있으면 모든 적은 가장 가까운 망자를 우선 공격하고, 망자가 없을 때 마왕을 공격합니다.

5웨이브마다 10초의 **휴식 시간**이 시작됩니다. 휴식이 시작되면 남아 있던 영웅이 모두 철수하고 마왕의 체력이 조금씩 회복됩니다. 망자·무기·방어구 뽑기는 휴식 중에만 가능하며, 한 번에 영혼 10개를 사용합니다.

## 적 종류

| 적 | 등장 | 특징 |
| --- | ---: | --- |
| 기사 | 1웨이브 | 기본 근접형 |
| 마법사 | 2웨이브 | 가벼운 마법형 |
| 중갑병 | 3웨이브 | 높은 체력 |
| 궁수 | 4웨이브 | 거리를 유지하며 화살 공격 |
| 암살자 | 6웨이브 | 매우 빠른 근접 공격 |
| 성기사 | 8웨이브 | 높은 체력과 강한 공격력 |
| 심연의 용사왕 | 10웨이브마다 | 전용 체력바를 가진 강적 |

처치한 적은 돈처럼 사용할 수 있는 **영혼 구슬**을 떨어뜨립니다. 가까이 다가가 흡수한 뒤 영혼 상점에서 사용할 수 있으며, 강적은 일반 적보다 훨씬 많은 영혼을 남깁니다.

모든 영웅은 처치될 때 **경험치 결정**도 떨어뜨립니다. 경험치를 모아 레벨업하면 스킬 포인트 1을 얻고 최대 체력이 5 증가합니다. 스킬 트리는 참고 이미지처럼 공격·방어·보조의 세 갈래로 나뉘며, 선행 스킬 조건을 만족하면 다음 노드를 해금할 수 있습니다.

| 영혼 상점 | 비용 | 효과 |
| --- | ---: | --- |
| `1` 마왕검 강화 | 15부터 증가 | 검격 공격력과 기본 공격력 영구 증가 |
| `2` 마왕 회복 | 12부터 증가 | 구매할수록 비용·회복량·최대 체력 증가량 상승 |
| `3` 마력 강화 | 18부터 증가 | 암흑탄·파멸의 낫·지옥불 피해와 범위 증가, 스킬 쿨타임 감소 |
| `4` 소환수 강화 | 20부터 증가 | 소환수의 공격력·속도·지속시간 영구 증가 |

## 망자와 인벤토리

소환한 망자는 시간 제한 없이 유지되고 서로 밀어내므로 같은 자리에 겹치지 않습니다. 기본 소환 상한은 12명이며 보조 스킬로 늘릴 수 있습니다. 소환되는 각 망자는 0.001% 확률로 체력 약 10배와 큰 추가 공격력을 가진 **엘리트 망자**가 됩니다. 각자 체력바를 가지며, 체력이 0이 되면 영혼 4개를 떨어뜨리고 사망합니다. 망자가 영웅을 직접 처치할 때마다 공격력과 최대 체력이 증가하며, 처치 수와 강화 레벨에 따라 더 강한 외형으로 바뀝니다. 플레이어·망자·영웅에는 이동 및 공격 모션과 검격 궤적이 적용됩니다.

인벤토리는 **방어구·무기·망자** 카테고리로 나뉩니다. 뽑기는 일반·고급·희귀·영웅·에픽·유일·전설·신화·태고·마왕의 10등급이며, 최고 마왕 등급 확률은 0.5%입니다. 중복 획득도 전투력으로 누적됩니다. 세 카테고리 모두 직접 장착할 수 있습니다. 무기를 장착하면 마왕의 검과 공격력이, 방어구를 장착하면 마왕의 갑옷·최대 체력·피해 감소가 바뀝니다. 망자 아이템을 장착하면 망자의 능력·3단계 이미지·등급 광채가 바뀝니다.

상단의 **인덱스**에서는 살아 있는 망자의 체력과 처치 성장, 영웅 종류, 10개 뽑기 등급의 확률을 확인할 수 있습니다. **전체화면** 버튼으로 브라우저 게임을 화면 전체에서 플레이할 수 있습니다.

상단의 **스킬 트리**에는 공격·방어·보조 총 15개 노드가 있습니다. 공격 속도·처형 피해·체력 재생·가시 갑주·망자 상한·지옥 건축술 등을 성장시킬 수 있으며 초기화하면 사용한 포인트를 돌려받습니다. **설정**에서는 걷기 모션, 화면 흔들림, 휴식 인벤토리 자동 열기를 켜고 끌 수 있습니다.

영혼을 사용해 확장된 전투 구역에 **영혼 포탑·망자의 벽·영혼 공장**을 배치할 수 있습니다. 포탑은 자동으로 영웅을 공격하고, 벽은 영웅의 공격을 받아내며, 공장은 일정 시간마다 영혼을 생산합니다. 지옥 건축술을 배우면 건설 비용이 감소하고 구조물 체력·공격·생산량이 증가합니다.

## 로컬 실행

```bash
pnpm install
pnpm dev
```

프로덕션 빌드:

```bash
pnpm build
pnpm start
```

## 저장

진행 상황은 브라우저에 3초마다 자동 저장됩니다. 웨이브·체력·현재 적과 망자는 **이어하기용 전투 저장**에 보관됩니다. 영혼·강화 단계·최대 체력·인벤토리·레벨·경험치·스킬 트리는 별도의 **영구 성장 저장**에 보관되어 마왕이 쓰러지거나 새 도전을 시작해도 유지됩니다. 강화와 뽑기 결과는 획득 즉시 저장됩니다.
