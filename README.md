# 마왕의 최종 방어선

마왕을 직접 조작해 왕좌로 몰려오는 용사들을 막는 브라우저 액션 디펜스 게임입니다.

## 바로 플레이

**[마왕의 최종 방어선 플레이하기](https://dum-sooez1111.github.io/ssr/)**

## 조작법

| 조작 | 행동 |
| --- | --- |
| `W` `A` `S` `D` | 이동 |
| 마우스 클릭 / `F` | 암흑탄 |
| 마우스 오른쪽 / `R` | 마왕검 휘두르기 |
| `Space` | 파멸의 낫 |
| `Q` | 지옥불 폭발 |
| `E` | 망자 3명 소환 — 쿨타임 없이 영혼 8 소비 |

웨이브는 끝없이 이어지며 10웨이브마다 강적 **심연의 용사왕**이 등장합니다. 모든 적은 왕좌가 아닌 마왕을 공격하며, 마왕의 체력이 0이 되면 도전이 종료됩니다.

5웨이브마다 10초의 **휴식 시간**이 시작됩니다. 휴식 중에는 새 적이 생성되지 않고 마왕의 체력이 조금씩 회복되며 영혼 상점을 계속 이용할 수 있습니다.

## 적 종류

| 적 | 등장 | 특징 |
| --- | ---: | --- |
| 기사 | 1웨이브 | 기본 근접형 |
| 마법사 | 2웨이브 | 가벼운 마법형 |
| 중갑병 | 3웨이브 | 높은 체력 |
| 궁수 | 4웨이브 | 거리를 유지하며 화살 공격 |
| 암살자 | 6웨이브 | 매우 빠른 근접 공격 |
| 성기사 | 8웨이브 | 높은 체력과 강한 공격력 |
| 심연의 용사왕 | 10웨이브마다 | 전용 체력바를 가진 강적 |

처치한 적은 돈처럼 사용할 수 있는 **영혼 구슬**을 떨어뜨립니다. 가까이 다가가 흡수한 뒤 영혼 상점에서 사용할 수 있으며, 강적은 일반 적보다 훨씬 많은 영혼을 남깁니다.

| 영혼 상점 | 비용 | 효과 |
| --- | ---: | --- |
| `1` 마왕검 강화 | 15부터 증가 | 검격 공격력 영구 증가 |
| `2` 마왕 회복 | 12 | 체력 35 회복 및 최대 체력 10 영구 증가 |
| `3` 마력 강화 | 18부터 증가 | 암흑탄과 지옥불 공격력 영구 증가 |
| `4` 소환수 강화 | 20부터 증가 | 소환수의 공격력·속도·지속시간 영구 증가 |

## 로컬 실행

```bash
pnpm install
pnpm dev
```

프로덕션 빌드:

```bash
pnpm build
pnpm start
```
