# 마왕의 최종 방어선

마왕을 직접 조작해 왕좌로 몰려오는 용사들을 막는 브라우저 액션 디펜스 게임입니다.

## 바로 플레이

**[마왕의 최종 방어선 플레이하기](https://dum-sooez1111.github.io/ssr/)**

## 조작법

| 조작 | 행동 |
| --- | --- |
| `W` `A` `S` `D` | 이동 |
| 마우스 클릭 / `F` | 암흑탄 |
| `Space` | 파멸의 낫 |
| `Q` | 지옥불 폭발 |
| `E` | 망자 소환 |

5번의 침공을 버티면 승리합니다. 마왕의 체력이나 왕좌의 내구도가 0이 되면 패배합니다.

## 로컬 실행

```bash
pnpm install
pnpm dev
```

프로덕션 빌드:

```bash
pnpm build
pnpm start
```
